# 추출 기준 budget-v1

대상: 01-미래청년기획관.pdf, 상세표 PDF 5~14쪽(인쇄 313~322쪽).

## 범위와 검증

조직·부서·정책·단위사업·세부항목·연도별 예산·예산과목별 배정·산출내역을 추출했다. 문서 구조 기반 초안이며 임의의 정책 주제 분류는 포함하지 않았다. 개요 인력, 기관임무, 개요 집계 금액은 이번 데이터에서 제외했다. 모든 페이지를 시각적으로 대조한 최종 검수본은 아니다.

26개 세부항목에는 기본경비 2개와 회계별 국고보조금 반환 2개가 포함된다. 산출내역 107개, 전체 노드 269개, 관계 345개. 26개 항목의 2026년 합계 106,542,798천원은 상세표 기관 총액과 일치한다. 모든 세부항목의 2026-2025 증감, 2026년 예산과목 합계, 산출내역 합계를 검사했다. 개요의 백만원 단위 반올림 금액으로 상세표를 덮어쓰지 않는다.

이름이 같은 기본경비·국고보조금 반환·인건비는 상위 문맥이 다르면 별도 엔티티다. 산출내역과 상위 예산을 함께 더하면 중복 집계된다. 2025년 상세 산출내역은 이 문서에 없어 생성하지 않았다. 2025년 0원은 신규 사업 확정 근거로 쓰지 않는다. X250,000 표기는 의미 미확정이므로 별도 재원 관계를 만들지 않았다.

예산과목별 배정(ExpenseAllocation)은 사업별·연도별 발생 기록이며 공통 과목 사전과 다르다. 공통 과목 분석이 필요하면 코드 사전을 추가한다. ID는 이번 추출 안에서만 유효한 순차 ID다. 운영 적재 전 문서 해시와 문맥 키로 안정적인 식별자를 설계해야 한다. 그래프를 Neo4j에 적재하거나 임베딩·GraphRAG를 실행하지는 않았다.

## 관계 사전

HAS_DEPARTMENT: 기관 → 부서
HAS_POLICY: 부서 → 정책
HAS_UNIT: 정책 → 단위사업
HAS_PROJECT: 단위사업 → 세부항목
RESPONSIBLE_FOR: 부서 → 소관 세부항목(직접 운영·수탁기관을 뜻하지 않음)
HAS_BUDGET: 세부항목 → 연도별 예산
HAS_EXPENSE: 2026년 예산 → 과목별 배정
HAS_LINE_ITEM: 과목별 배정 → 산출내역
EVIDENCED_BY: 예산 → 문서

노드·관계의 pdf_page는 1부터 시작한다. printed_page는 원문 인쇄 쪽수다. 예산 금액 단위는 천원이며 BudgetAllocation에는 amount_krw도 저장한다. 관계의 basis는 document_structure다.

## 기준을 바꿀 때

A 문서 구조: 조직·사업 계층 보존. 문서의 분류를 설명한다.
B 지출 분석: 예산·과목·산출내역 보존. 금액 구성과 연도 비교에 적합하다.
C 의미 탐색: 사업 → 주제·지원방식 관계를 추가. 별도 분류 버전·분류 근거·추론 상태가 필요하다. 기본 사실 노드는 보존한다.
D 복수 문서: 사업 → 주장 → 출처 구조 추가. 연도·회계·예산 단계(안/확정/추경/결산)·발행일을 분리한다. 서로 다른 금액을 자동으로 덮어쓰지 않는다.

## 파일에 맞는 기준 추천

확장자는 추출기를 고르는 단서다. PDF라는 이유로 예산 그래프를 선택하지 않는다. 실제 내용, 표/서술/조문 비중, 반복 키, 날짜·단위·문서 간 참조, 추출 품질을 검사해 문서별·구간별 모델을 추천한다.

예산표: A+B. 공고문: 사업·대상·자격조건·기간·신청절차. 회의록: 회의·참석자·안건·결정·조치. 계약서: 당사자·의무·조건·기한. 보고서: 주장·지표·관측값·방법·근거. 혼합 문서: 구간별 모델 + 공통 출처 계층.

복수 파일은 각각 구조를 먼저 추출한 뒤 공통 사업·조직을 연결한다. 이름만으로 병합하지 않는다. 불확실한 동일성은 병합 후보로 남긴다. 기준 추천은 근거·대안·불확실성·표본 그래프를 함께 보여주는 방식이 적합하다. 현재 자동 추천 시스템을 구현한 것은 아니다.
