# 범용 문서 분석·엔티티·관계 추출

기본 템플릿은 [범용 프롬프트](universal-prompts.md)입니다. 특정 업무의 엔티티·관계를 고정하지 않고 문서 구조에서 기준을 제안한 뒤, 확정 profile을 추출기에 전달합니다.

1. 문서 구조 분석
2. 추출 기준 제안·표본 확인
3. 확정 기준으로 구간별 추출
4. 문서 간 동일성·충돌 검토
5. 오류 구간 재검토

각 단계는 별도 호출합니다. 구조 분석·기준 설계와 사실 추출을 한 번에 맡기지 않습니다. 사용자에게는 중요한 의미 선택만 질문하고, 기존 기준으로 충분한 문서는 재사용합니다.

기존 예산 전용 내용은 [예산 문서 적용 예시](budget-prompt-example.md)에 보존했습니다. 이 예시는 범용 규칙이 아닙니다.

실제 모델 호출·JSON Schema 생성·검증·승인 UI는 아직 앱에 연결되어 있지 않습니다. 프롬프트를 범용화한 것이며 현재 Python 추출기는 여전히 해당 예산 PDF 전용입니다.
